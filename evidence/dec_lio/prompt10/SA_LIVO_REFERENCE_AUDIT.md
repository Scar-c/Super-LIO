# SA-LIVO / SAIF paired-information reference audit

Primary reference audited: https://arxiv.org/html/2606.25699v2
(arXiv:2606.25699, official HTML version 2).

The relevant authority is the paired spectral reconstruction: scale an
eigenvalue and its corresponding transformed RHS component by the same
`gamma`, preserving PSD by construction and preserving the isolated modal
minimizer. The reference also describes a square-root information amplitude
gate. Prompt10 adopts only this paired-information principle; it does not
copy a visual/semantic gate, a learned policy, or a Prob-LIO estimator.
