# Dec-LIO evidence

This directory stores reproducibility evidence, never bags or ROS logs. See
`EVIDENCE_INDEX.md` for the Prompt00R, Prompt01, Prompt02, and Prompt03 closure maps.
Historical evidence is namespaced under `prompt00r/` and `prompt01/`; new
Prompt02 evidence is under `prompt02/`, and Prompt03 evidence is under
`prompt03/`.
