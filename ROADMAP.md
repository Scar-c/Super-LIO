# Dec-LIO roadmap authority

This file is the sole roadmap authority for the Dec-LIO line. It intentionally
contains future work only; no future item is enabled by the native baseline.

| ID | Scope | Status | Exit condition |
|---|---|---|---|
| D0 | Clean ROS1/native baseline and evidence closure | active | Prompt00R gates pass |
| D1 | Algorithm-neutral observability and replay diagnostics | planned | reviewed design plus tests |
| D2 | Deterministic transport/back-pressure instrumentation | planned | invariant-preserving evidence |
| D3 | Exact paired online/offline regression harness | planned | adversarial tests and CI policy |
| D4 | Optional native estimator improvements | planned | separate approved prompt and ablation |
| D5 | Prob-LIO estimator work | not authorized | requires a new explicit authority |

D1–D4 are not implemented in this baseline. D5 is explicitly out of scope.
