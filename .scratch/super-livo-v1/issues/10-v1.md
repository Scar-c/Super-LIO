# 10: [Super-LIVO v1][V-1] Add event-triggered visual geometry reparameterization

## Source specification

`docs/super_livo/specs/super_livo_v1_spec.md` → **对应 TB 节**；`docs/super_livo/redesign/architecture_owner_decisions.md`。

## Goal

E1 OR E2 触发的 geometry reparameterization（重算 anchor/plane snapshot/warp geometry）；N=20 final freeze 语义。

## Why this tracer bullet exists

平面变化不触碰 photometric source；禁止 chained patch resampling（patch0→patch1→patch2）。

## What changes

sync 事件（E0 first valid force-sync；E1 valid→valid 累积 normal change；E2 valid→valid anchor/depth change；E3 valid→invalid deactivate；E4 N=20 force final sync + freeze；invalid→valid force sync）；reparameterization 仅重算 anchor/snapshot/warp。

## What does NOT change

immutable reference patch / pixel/ray / camera pose/id；无 chained interpolation；NO photometric state update。

## Architectural invariants

E1 比较 current vs last-sync（非相邻帧）；E2 优先 ray depth/anchor shift；阈值 defer to DG-0。

## Likely source seams

V-0 snapshot + G-0 stats 事件检测。

## Instrumentation

sync 事件计数、reparameterization 计数。

## Tests required

事件状态机单测（E0-E4 全路径、invalid→valid 再同步）+ 无 chained warp 断言。

## Dataset / execution policy

eee_01（offline）。

## Acceptance criteria

- [ ] E0..E4 全路径状态机测试通过（含 VALID→INVALID deactivate 与 INVALID→VALID force sync）。
- [ ] N=20 后 μ/S/n/plane_valid 冻结断言（frozen 测试）。
- [ ] 不存在 patch→patch chained resampling 代码路径（review+测试）。
- [ ] reparameterization 输出 anchor/snapshot 更新而 reference patch 字节不变。

## Failure rules

chained resample / freeze 失效 / 事件语义错 → FAIL。
