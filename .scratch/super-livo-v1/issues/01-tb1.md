## Goal

Camera input / calibration only：camera message ingestion、标定加载、时间戳记账、有界缓冲、offline camera backend extension seam；对 estimator 零影响。

## Why this tracer bullet exists

G-1 起需要 camera FOV/patch border 投影；先建立"camera 存在但完全惰性"的 safe 状态（v1 spec TB-1；原 v0 TB-1 语义保留）。

## What changes

HandleImage 进入统一 Handle seam（与 HandleImu/HandleLidar 同层）；标定结构（intrinsics/distortion/T_cam_imu/time_offset）；bounded ring buffer；offline backend camera topic dispatch（正式首支持 eee_01）；为 eee_01/Corridor01/SFS 预留统一 camera interface。

## What does NOT change

state/covariance/LiDAR sync/map/trajectory 零影响；LiDAR-end estimator 时序；NO camera-epoch sync；NO VisualMap；NO photometric residual。

## Architectural invariants

I-04（图像归属 bounded buffer）；ADR-002 seam 语义（未来 camera-only 不被卡死）。

## Likely source seams

ROSWrapper（Handle 方法）、offline backend（camera dispatch，eee_01 的 /left/image_raw 等）、params。

## Instrumentation

camera 消息计数、buffer depth、camera timestamp accounting。

## Tests required

标定解析（非法输入报错）、buffer 有界、legacy parity。

## Dataset / execution policy

eee_01（offline backend；camera 仅缓冲）。

## Acceptance criteria

- [ ] camera/enabled=false：eee_01 全量 trajectory MD5 与 TB-0 baseline 完全一致（9af9b9d9b7fdeda4ffcd031b9f0cb544，3981 samples）。
- [ ] camera enabled（仅缓冲、visual influence disabled）：estimator 状态路径不变（同 parity 规则）。
- [ ] buffer 容量恒 ≤ capacity（有界，无泄漏增长）。
- [ ] camera timestamps accounted（header.stamp + time_offset，无 estimator 使用）。
- [ ] 标定参数缺失/非法 → 启动报错退出。
- [ ] 标定加载确定性（同一输入 → 同一结果，测试断言）。

## Failure rules

camera 影响 estimator/轨迹/地图 → FAIL；允许改 buffer/标定/Handle seam；禁止让 camera 参与同步或状态。
