## Goal

记录 micro-surfel 成熟度（first visible → N5 → plane-valid → N=20）与 geometry sync 事件频率（1°/2°/3°/5°）。

## Why this tracer bullet exists

回答"地图成熟时视觉是否来得及挂载"与"sync 事件频率"——DG-0 与 V-1 阈值依据。

## What changes

每 micro-surfel 记录 first visible / first N≥5 / first plane-valid / N=20 final epoch；输出 median/P90（first-visible→N5、→plane-valid）、mature_while_visible_ratio、plane_valid_while_visible_ratio；E1（current vs last-sync normal）与 E2（ray depth/anchor shift）事件计数。

## What does NOT change

NO state feedback；NO VIO update；estimator 不变。

## Architectural invariants

E1 OR E2 已冻结；3° 仅 candidate starting point（非理论最终值）；最终阈值 defer to DG-0。

## Likely source seams

G-1 visibility 关联 + G-0 stats 时间线。

## Instrumentation

事件计数落盘（feasibility_stats）。

## Tests required

合成时间线单测（人为构造 visibility/maturity 序列）。

## Dataset / execution policy

eee_01（offline）。

## Acceptance criteria

- [ ] median/P90（first visible→N5、→plane-valid）输出。
- [ ] 1°/2°/3°/5° 的 sync event rate 分布输出（只记录，不选最终阈值；不以 ATE 选值）。
- [ ] mature_while_visible_ratio 与 plane_valid_while_visible_ratio 输出。
- [ ] "camera 在 N=2 时看到、离开后 N 才成熟"占比报告。

## Failure rules

事件定义含糊、计数缺失、以 ATE 定阈值 → FAIL。
