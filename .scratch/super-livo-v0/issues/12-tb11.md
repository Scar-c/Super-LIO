## What to build

```text
x_prop, P_prop
  → normal LiDAR nonlinear search → x_search
  → x_F = x_search
  → reuse final correspondence（缓存）
  → rebuild r_L(x_F), H_L(x_F)
  → Λ_L^F, b_L^F
  → from (x_prop, P_prop) final LiDAR update → (x_L, P_L)
```

- instrumentation：每帧输出 ‖Δp_F‖、‖Δθ_F‖（Δx_F = x_L ⊖ x_F）与 Λ_L eigenvalues。
- OPEN-01 数据采集：ΔF 分布（translation / rotation 分别 median / P90 / P95 / P99 / max）落盘；**不设置 re-anchor threshold**。
- 前置合成 oracle：joint solve vs sequential linear Gaussian solve 一致性单测（spec TB-12 节与 Testing 节定义；本 TB 落地该测试）。
