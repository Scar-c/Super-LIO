# 10: [Super-LIVO v0][TB-9] Enable MODE-A sequential visual state updates

**Status:** ready-for-agent

## Parent

本地 tracker parent：`00-parent.md`（Super-LIVO v0 — Camera-Epoch Sequential LIVO with Common-FEJ）

## Source specification

`docs/super_livo/specs/super_livo_v0_spec.md` → **TB-9 节**、**FEJ Modes 节**（MODE-A）、ADR-003。

## Goal

第一次让 camera 修改 estimator state：MODE-A Sequential（no FEJ）。VIO：current residual + current Jacobian + iterative relinearization；VIO prior = (x_L, P_L)。

## Why this tracer bullet exists

建立视觉状态反馈的干净 baseline（无任何线性化冻结），后续 MODE-B/C 消融都以它为对照。

## What to build

- mode `livo_sequential`：ESKF second update（TB-3 API）接入视觉 streaming 观测（TB-8 产物）。
- 视觉 correction 诊断：visual active / accepted / rejected count、‖Δp_visual‖、‖Δθ_visual‖、residual mean/median/P90/P95/P99、Λ_C condition/eigenvalues。
- basic safety gates（spec 定义的四件套）：geometric visibility / image bounds / finite intensity / photometric residual hard gate（`/visual/outlier_gate`，默认 1000）。

## Explicit non-goals

- NO FEJ / NO Common-FEJ / NO adaptive noise / NO exposure state。
- 不以 ATE 提升作为 correctness gate。
- robust kernel 不进本 TB 主路径（默认 "none"；kernel 是独立实验变量）。

## Architectural invariants

- I-07：VIO prior = (x_L, P_L)。
- ADR-004 MODE-A 定义。

## Likely code seams

- ESKF second update（TB-3）+ orchestrator 模式调度（`livo/`）+ visual observation。

## Tests required

- dataset（Tier 1）+ correction 诊断。
- component：visual OFF 复现性。

## Acceptance criteria

- [ ] finite trajectory / finite covariance / no explosive correction / bounded visual residual / bounded iteration count。
- [ ] mode=lio_camera_epoch（visual OFF）时 exactly reproduces pre-TB9 行为（与 TB-2 camera-epoch 输出一致，同 parity 规则）。
- [ ] 每 camera update 输出：visual active/accepted/rejected count、‖Δp_visual‖、‖Δθ_visual‖、residual mean/median/P90/P95/P99、Λ_C condition/eigenvalues。
- [ ] 无 ATE 断言（spec 明确不以 ATE 提升为门槛）。

## Runtime / memory / debug artifacts

- visual_stats.csv（上述诊断）；timing.csv 增加 visual update 计时。

## Failure rules

- FAIL：爆炸性修正、残差无界、iteration 失控、visual OFF 不再复现 pre-TB9。
- 允许改：视觉实现细节（投影/残差/gate）。
- 禁止用于救场：为了 ATE 调噪声 / 换 kernel / 改 FEJ / 加 adaptive R。
