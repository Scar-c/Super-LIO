# 08: [Super-LIVO v0][TB-7] Validate direct photometric residual and analytic Jacobian in shadow mode

**Status:** ready-for-agent

## Parent

本地 tracker parent：`00-parent.md`（Super-LIVO v0 — Camera-Epoch Sequential LIVO with Common-FEJ）

## Source specification

`docs/super_livo/specs/super_livo_v0_spec.md` → **TB-7 节**、**Mathematical Models 节**、Round 2 §23/§24（photometric baseline、OPEN-02）。

## Goal

在 shadow mode 下实现并验证 direct photometric residual r_C 与 analytic Jacobian J_C（**DO NOT feed correction into ESKF**）。

## Why this tracer bullet exists

这是 safety gate：任何视觉状态反馈（TB-9）之前，必须先证明残差与 Jacobian 数学正确（FD 验证），否则后续无法归因。

## What to build

- r_C：bilinear sampling + plane-aware warp + 固定 exposure metadata（无 exposure 状态，DECISION-17）；无 NCC / adaptive noise / complex calibration。
- analytic J_C：图像梯度 × 投影 Jacobian（针孔） × pose Jacobian，**在 ESKF 右扰动误差态下表达**（与 LiDAR J 同 tangent space，super_lio.cpp:487-493 约定）；外参固定不进状态。
- pyramid 首版：**sampling-stride**（FAST-LIVO2-compatible，作为 implementation baseline，不代表最终 architecture choice；接口不绑定 pyramid 表示，OPEN-02）。
- FD validation harness：central difference；rotation 与 translation 分别验证；多个 image points / depths / poses。
- shadow 评估输出残差统计，不喂 ESKF。

## Explicit non-goals

- state feedback = OFF；不修改 ESKF；无 FEJ；无 adaptive noise；无 exposure state。
- 不实现 true image pyramid（OPEN-02 延后 A/B）。
- 不实现 patch replacement 策略（OPEN-03；patch 创建后 immutable，只留 seam）。

## Architectural invariants

- ADR-005 pipeline 边界（PhotometricEvaluator 不拥有全局 map）。
- OPEN-02：接口不绑定 pyramid 表示。

## Likely code seams

- 新 `visual/PhotometricEvaluator`。

## Tests required

- photometric Jacobian FD unit（这是硬性前置 gate）。

## Acceptance criteria

- [ ] median relative error < 1e-4（e_rel = ‖J_A − J_FD‖ / max(‖J_FD‖, ε)）。
- [ ] P95 relative error < 1e-3。
- [ ] rotation 与 translation 分别验证；覆盖多个 image points / depths / poses。
- [ ] shadow 残差统计落盘（visual_stats.csv），且 ESKF 状态不变（无 feedback 断言）。
- [ ] 采样行为与 FAST-LIVO2-compatible stride 一致，并在代码/文档标注 reference source、Super-LIVO adaptation、原因（round0 §7.2 参考）。
- [ ] 若数值尺度导致 gate 不合理：报告完整数据（不得静默放宽）。

## Runtime / memory / debug artifacts

- visual_stats.csv（shadow residual mean/median/P90/P95/P99）。
- FD 验证结果文件（e_rel 分布）。

## Failure rules

- FAIL：FD gate 不通过、shadow 结果不落盘、Jacobian 与右扰动约定不一致。
- FD FAIL 时**只允许**修：frame convention / projection chain / residual / Jacobian / interpolation。
- **禁止**通过 visual noise、robust kernel、FEJ、adaptive R "救" FD gate（直到 FD PASS）。
