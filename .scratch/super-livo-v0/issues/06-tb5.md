# 06: [Super-LIVO v0][TB-5] Couple visual lifetime to geometry eviction

**Status:** ready-for-agent

## Parent

本地 tracker parent：`00-parent.md`（Super-LIVO v0 — Camera-Epoch Sequential LIVO with Common-FEJ）

## Source specification

`docs/super_livo/specs/super_livo_v0_spec.md` → **TB-5 节**、**Visual Map Lifecycle 节**、**APIs 节**（EvictedKeys）、ADR-006。

## Goal

把 VisualMap 生命周期耦合到 geometry eviction：geometry eviction 暴露 evicted KEY(s) → orchestrator → VisualMap.erase(keys)。OctVox 不知道 VisualMap。

## Why this tracer bullet exists

ADR-006（DECISION-19/20）：ownership 单一（OctVoxMap→geometry、VisualMap→visual、orchestrator→lifecycle）；VisualVoxel lifetime ≤ GeometryVoxel lifetime。

## What to build

- OctVox eviction 向调用层暴露被淘汰 KEY（概念 API：`UpdateMap(..., EvictedKeys* evicted)`，具体签名按 spec 由实现确定）。
- orchestrator 收到 evicted keys 后执行 `VisualMap.erase(keys)`。
- `resetMap()/clear()` 路径同样传播清空（Round 0 §4.3 注意点）。
- automated eviction 测试（极小 capacity 强制淘汰）。

## Explicit non-goals

- 不让 OctVoxMap 感知 VisualMap（无 callback/object pointer 存储）。
- 不改 LRU 语义与 eviction 触发条件。
- 不做视觉点创建、不做 state update。

## Architectural invariants

- I-02：VisualMap 必须 bounded。
- ADR-006：VisualVoxel lifetime ≤ GeometryVoxel lifetime。

## Likely code seams

- `include/OctVoxMap/OctVoxMap.hpp`（insert 淘汰点 287-300、clear/resetMap）。
- `super_lio.cpp` UpdateMap 调用点。
- orchestrator（推荐 `livo/` 模块）。

## Tests required

- eviction unit（small capacity，如 16 voxel）+ component（resetMap 传播）。

## Acceptance criteria

- [ ] 极小 capacity 强制 eviction 的 automated test：geometry key evicted → 对应 key 的 VisualVoxel 被移除（断言，非人工观察）。
- [ ] 测试断言 VisualMap size ≤ geometry 存活 key 数（bounded）。
- [ ] resetMap/clear 路径后 VisualMap 同步清空（component）。
- [ ] OctVoxMap 代码中无 VisualMap 类型/引用（review + 依赖检查）。
- [ ] 被淘汰 voxel 下帧重新观测 re-insert 时，VisualMap 可正确重新创建条目（无孤儿/陈旧状态）。

## Runtime / memory / debug artifacts

- map_stats.csv：VisualVoxel count（bounded 断言数据）。

## Failure rules

- FAIL：eviction 未传播、visual 残留孤儿 key、bounded 违反、测试无法自动化。
- 允许改：evicted 容器形态、orchestrator 回调位置。
- 禁止用于救场：让 OctVoxMap 直接感知 VisualMap；放宽 bounded 要求。
