# 01: [Super-LIVO v0][TB-0] Freeze baseline and add instrumentation

**Status:** ready-for-agent

## Parent

本地 tracker parent：`00-parent.md`（Super-LIVO v0 — Camera-Epoch Sequential LIVO with Common-FEJ）

## Source specification

`docs/super_livo/specs/super_livo_v0_spec.md` → **TB-0 节**（Tracer Bullets）、**Instrumentation 节**、**Experiment Protocol 节**。

## Goal

在任何功能变化之前建立 Super-LIO 的可重复 baseline（timing / map stats / LIO stats / trajectory / run manifest），供后续所有 parity 与 overhead 对照。

## Why this tracer bullet exists

TB-1 的 legacy parity、Runtime Gate（overhead ≤ 5%）都以本 TB 的 baseline 为参照；没有可信 baseline 则后续任何变化无法归因。

## What to build

只增加 instrumentation 与实验基础设施，不改算法：

- per-frame 计时：IMU propagation / undistortion / downsample / state update / map update / total。
- map 统计：OctVox voxel count、estimated map bytes。
- LIO 统计：effective point count、iteration count、residual statistics。
- trajectory 落盘：timestamp + pose（tum 格式）。
- run_manifest 生成：git SHA、dirty status、build type、config path/hash、dataset、bag path/name、playback rate、mode、sync mode、camera enabled、start/end time、hostname、CPU。
- results/<experiment>/<run_id>/ 独立输出目录与 CSV writer；experiment runner 支持"新进程 + 新目录"的重复运行。

## Explicit non-goals

- 不改任何算法语义（状态/协方差/同步/地图/轨迹）。
- 不新增 camera / 视觉 / FEJ。
- 不改变任何参数默认值。

## Architectural invariants

- I-01：OctVox geometry payload 保持 compact（instrumentation 不得向每个 voxel 增加固定成本）。

## Likely code seams

- 现有 `include/common/timer.h`（Timer 计时风格）。
- `super_lio.cpp` process 管线内插桩点。
- 推荐新模块：`livo/`（sync、orchestrator、instrumentation），遵循仓库 `include/<module>/` + `src/<module>/` 布局。

## Tests required

- component：manifest 字段完整性、CSV 格式稳定。
- dataset experiment：3 独立进程重复性（Tier 1 数据，TB-0 Gate）。

## Acceptance criteria

- [ ] 相同输入重复运行 3 个**独立进程**（每次终止前一次 ROS node、启动全新进程、独立输出目录；禁止单进程循环 3 次；默认不 reboot）。
- [ ] 3 个 run 的 timing.csv / lio_stats.csv / map_stats.csv 数值在浮点合理范围内一致（脚本 diff）。
- [ ] 3 个 run 的 trajectory.tum sample count 与 timestamps 完全一致。
- [ ] run_manifest.yaml 至少包含：git SHA、dirty status、build type、config path/hash、dataset、bag path/name、playback rate、mode、sync mode、camera enabled、start/end time、hostname、CPU。
- [ ] per-frame timing 至少包含 IMU propagation / undistortion / downsample / state update / map update / total。
- [ ] map stats 至少包含 OctVox voxel count 与 estimated map bytes；LIO stats 至少包含 effective point count / iteration count / residual statistics。
- [ ] 除新增 instrumentation 输出外，算法输出（轨迹/地图/状态）与无插桩基线一致（同输入 MD5 或最大 delta 报告）。

## Runtime / memory / debug artifacts

`results/<experiment>/<run_id>/{trajectory.tum, timing.csv, lio_stats.csv, map_stats.csv, run_manifest.yaml, ros_stdout.log}`

## Failure rules

- FAIL：计数器缺失、3 进程结果不重复、manifest 不完整、输出目录结构不稳定。
- 允许改：stats 结构、CSV writer、manifest writer、runner。
- 禁止用于救场：改算法、改噪声、改参数默认值。
