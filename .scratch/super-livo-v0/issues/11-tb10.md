# 11: [Super-LIVO v0][TB-10] Enable MODE-B VIO-FEJ

**Status:** ready-for-agent

## Parent

本地 tracker parent：`00-parent.md`（Super-LIVO v0 — Camera-Epoch Sequential LIVO with Common-FEJ）

## Source specification

`docs/super_livo/specs/super_livo_v0_spec.md` → **TB-10 节**、**FEJ Modes 节**（MODE-B）、ADR-003/ADR-004。

## Goal

启用 MODE-B VIO-FEJ：x_F = x_L；VIO residual r_C = r_C(x_cur)、Jacobian H_C = H_C(x_F)（冻结）。必须可证明 Jacobian 真被冻结。

## Why this tracer bullet exists

FEJ 消融第二档（VIO 侧单独冻结），与 MODE-A 对照度量 VIO-FEJ 收益；同时建立"冻结可证明"的机制（checksum），供 MODE-C 复用。

## What to build

- mode `livo_vio_fej`：FEJ anchor = x_L（LIO posterior）；同一 visual update 内**冻结 active set**；H 在 x_F 求值。
- FEJ anchor id/version 与 H checksum（或 selected Jacobian checksum）记录；同一 update 不同 iteration 内 H geometry 必须不变（除非 active set 显式改变或 robust/noise weighting 改变 normal equation）。
- 除 linearization policy 外与 MODE-A 完全一致（公平消融）。

## Explicit non-goals

- 不冻结 residual（r 保持 current）。
- 无 Common-FEJ；无 adaptive noise；无 exposure state。
- 不改变 prior 语义（VIO prior 仍是 (x_L, P_L)，FEJ 只是 Jacobian 求值点）。

## Architectural invariants

- I-06：Sequential prior ≠ FEJ anchor；fixed prior ≠ FEJ。
- ADR-004 MODE-B 定义。

## Likely code seams

- ESKF observation context（LinearizationAnchor 传入）、visual observation、`livo/` 模式调度。

## Tests required

- FEJ freeze unit（H checksum 跨 iteration 不变）。
- dataset（Tier 1）与 MODE-A 对照。

## Acceptance criteria

- [ ] 同一 camera update 的所有 iteration 中，FEJ geometry/Jacobian checksum 不变（automated 断言）。
- [ ] 同一 visual update 内 active set 不变（点集 id 快照断言）。
- [ ] FEJ anchor id/version 与 H checksum 落盘 fej_stats.csv。
- [ ] residual 仍按 current 计算（扰动测试/checksum 证明 residual 未冻结）。
- [ ] 除 linearization policy 外，与 MODE-A 共享相同输入/同步/VisualMap/点集/patch/outlier gate/iteration/噪声/map lifecycle（脚本可对比配置）。
- [ ] VIO prior 仍为 (x_L, P_L)（测试断言 prior 语义）。

## Runtime / memory / debug artifacts

- fej_stats.csv（anchor id/version、H checksum、iteration 级校验）。

## Failure rules

- FAIL：checksum 显示 H 变化、active set 未冻结、prior 回 mixed-anchor、residual 被误冻结。
- 允许改：anchor 版本管理、checksum 实现。
- 禁止用于救场：把 residual 也冻结（那不是 MODE-B）；用 FEJ 掩盖 TB-9 问题。
