# 02: [Super-LIVO v0][TB-1] Add zero-impact camera input

**Status:** ready-for-agent

## Parent

本地 tracker parent：`00-parent.md`（Super-LIVO v0 — Camera-Epoch Sequential LIVO with Common-FEJ）

## Source specification

`docs/super_livo/specs/super_livo_v0_spec.md` → **TB-1 节**、**Configuration 节**（`/camera/*`）、**Synchronization Semantics P1**。

## Goal

加入 zero-impact camera input：subscriber、标定加载、camera timestamp、有界帧缓冲。camera 只进 buffer，对 state / covariance / LiDAR sync / map / trajectory 零影响。

## Why this tracer bullet exists

相机输入是后续所有视觉 TB 的前提；先建立"camera 存在但完全惰性"的 safe 状态，保证不会污染既有 LIO 基线。

## What to build

- `/camera/enabled`（默认 false）、`/camera/topic`、`/camera/intrinsics`（fx, fy, cx, cy, k1, k2, p1, p2, k3）、`/camera/distortion_model`（v0 仅 radtan）、`/camera/T_cam_imu`（3 + 9，风格同 `/lio/extrinsic/lidar_imu`）、`/camera/time_offset`、`/camera/exposure_time`（固定 metadata）、`/camera/frame_buffer_capacity`（默认 10）。
- camera subscriber 与 timestamp 计算（header.stamp + time_offset + exposure metadata）。
- bounded ring buffer；标定参数缺失/非法时启动报错。
- 参数风格：`nh.getParam` + `g_` 全局变量（现有 params.cpp 约定）。

## Explicit non-goals

- camera 对 state / covariance / LiDAR synchronization / map / trajectory 零影响。
- 不做 recombination、不做视觉、不做 FEJ、不做 adaptive noise。
- 不改变现有 LIO 任何行为。

## Architectural invariants

- I-04：完整图像属于 bounded frame/ring buffer，生命周期有限。

## Likely code seams

- `ROSWrapper.cpp` 订阅区（现有 subLidar_/subIMU_ 模式）。
- `params.cpp/params.h`（`g_` 风格参数加载）。
- 推荐新模块：`livo/sync`（相机缓冲归属）。

## Tests required

- component：标定解析（合法/非法输入）、buffer 有界性。
- ROS integration：parity（camera enabled=false 与 enabled=true 对照）。

## Acceptance criteria

- [ ] `camera/enabled=false` 时，trajectory sample count 与 TB-0 baseline **完全相等**。
- [ ] 每个输出 timestamp 与 baseline timestamp 序列**完全相等**（先 MD5 比对 trajectory.tum；若不能 bitwise identical，报告最大 pose delta；不得用 ATE 掩盖内部差异）。
- [ ] `camera/enabled=true` 且 mode=lio_only_legacy 时（相机仅入 buffer），trajectory / map / state 输出与 `camera/enabled=false` 一致（同一 parity 规则）。
- [ ] 标定参数缺失/非法（intrinsics 长度、T_cam_imu 长度、未知 distortion model）时启动报错退出。
- [ ] frame buffer 容量恒 ≤ frame_buffer_capacity（有界，无泄漏增长）。

## Runtime / memory / debug artifacts

- map_stats.csv 或新字段：frame cache bytes。

## Failure rules

- FAIL：camera enabled 时任何状态/轨迹/地图差异、标定错误未报、buffer 无界。
- 允许改：frame buffer 结构、标定解析、camera diagnostics。
- 禁止用于救场：让 camera 影响同步或状态；放宽 parity 定义。
