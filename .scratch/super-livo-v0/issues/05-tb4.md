# 05: [Super-LIVO v0][TB-4] Introduce compact sparse visual-map data structures

**Status:** ready-for-agent

## Parent

本地 tracker parent：`00-parent.md`（Super-LIVO v0 — Camera-Epoch Sequential LIVO with Common-FEJ）

## Source specification

`docs/super_livo/specs/super_livo_v0_spec.md` → **TB-4 节**、**Data Structures 节**、ADR-002。

## Goal

建立 compact sparse visual-map 数据结构：CameraFrame / VisualLandmark / VisualVoxel / VisualMap。**NO photometric state update**。

## Why this tracer bullet exists

ADR-002 决定 VisualMap 是独立 sparse side-table（不嵌入 OctVox payload），VisualLandmark 3D anchor immutable、不持有完整图像；本 TB 把这些约束落成实际类型。

## What to build

- VisualLandmark v0 字段：immutable `p_ref_world`、immutable `normal_ref`、`ref_pixel`、内联固定 `ref_patch`（patch_size=8 → 64 float，无 per-landmark heap 分配）、`ref_frame_id`、compact `ref_pose`、`score`、`last_seen`、`age`、`source`（v0 恒 LIDAR_ANCHORED；CAMERA_ONLY 只留 seam）。
- VisualVoxel：内联小容量（`/visual/landmarks_per_voxel` 默认 4），溢出按 score 淘汰。
- VisualMap：`robin_map<KEY, VisualVoxel>`（与 OctVoxMap 共享 voxel key convention），insert / query / erase。
- CameraFrame：timestamp、灰度图（归属 bounded ring buffer）、exposure metadata（固定值）、camera model（radtan 针孔）；pyramid access 抽象（v0 为 sampling-stride，接口不绑定表示）。
- 内存计数器（VisualVoxel count / VisualLandmark count / reference patch bytes / container estimated bytes / frame cache bytes）。

## Explicit non-goals

- NO photometric state update。
- 不实现 camera-only（只保留 source 字段 seam）。
- 不把视觉数据嵌入 OctVox（禁止 visual_id[8] 一类固定索引）。
- VisualLandmark 不得持有 full cv::Mat；不得持有 mutable OctVox representative 指针/引用。

## Architectural invariants

- I-02：Visual storage sparse 且 bounded。
- I-03：Visual 3D reference anchors 不跟随 OctVox averaging。
- I-04：Full images 不被 long-lived landmarks 拥有。
- I-01：OctVox geometry payload 保持 compact。

## Likely code seams

- 推荐新模块：`include/visual/` + `src/visual/`（CameraFrame、VisualLandmark、VisualMap…）。
- 复用 tsl::robin_map（现有 3rdparty/include 内）。

## Tests required

- VisualMap unit（insert/query/erase、内联容量淘汰）。

## Acceptance criteria

- [ ] VisualLandmark 无 full cv::Mat 成员（类型断言）。
- [ ] VisualLandmark 无指向 mutable OctVox representative 的指针/引用。
- [ ] VisualMap 不是嵌入每个 OctVox 的字段；OctVox payload 不变（sizeof/内存佐证）。
- [ ] `p_ref_world` / `normal_ref` 创建后不可变（const 语义 + unit 断言）。
- [ ] patch 为内联固定数组，无 per-landmark heap 分配。
- [ ] 内存计数器可打印：VisualVoxel count / VisualLandmark count / reference patch bytes / container estimated bytes / frame cache bytes。
- [ ] VisualVoxel 溢出按 score 淘汰（unit）。

## Runtime / memory / debug artifacts

- map_stats.csv：上述 5 项内存计数。

## Failure rules

- FAIL：违反 I-03/I-04、嵌入 OctVox、持有 cv::Mat、landmark 跟随 averaging。
- 允许改：字段布局、内联容量、容器选择。
- 禁止用于救场：让 VisualMap 影响 LIO；把视觉数据塞进 OctVox payload。
