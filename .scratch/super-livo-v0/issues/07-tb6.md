# 07: [Super-LIVO v0][TB-6] Create LiDAR-anchored visual landmarks

**Status:** ready-for-agent

## Parent

本地 tracker parent：`00-parent.md`（Super-LIVO v0 — Camera-Epoch Sequential LIVO with Common-FEJ）

## Source specification

`docs/super_livo/specs/super_livo_v0_spec.md` → **TB-6 节**、ADR-002（DECISION-13）。

## Goal

创建 LiDAR-anchored VisualLandmark（active 200–500 / image），严格复用 LIO 已产出的数据，禁止额外 HKNN / plane fitting。

## Why this tracer bullet exists

DECISION-13：候选视觉点优先复用 LIO 已得到的 valid LiDAR point + fitted plane normal + association quality；"不要为了生成视觉点重新 HKNN"。这是第一版唯一视觉点来源。

## What to build

Selection pipeline（按 spec 接口定义）：

```text
effective LiDAR point
  → valid plane geometry（复用 abcd_vec_ / effect_mask_ / points_body_v3_ 等）
  → transform/project into camera（T_cam_imu + pose）
  → inside valid image region
  → sufficient photometric quality（gradient/Shi-Tomasi-like）
  → image-grid competition（每 cell 单点）
  → create VisualLandmark（冻结 p_ref_world / normal_ref）
```

- 明确区分并分别计数：active candidates/image 与 total persistent VisualMap landmarks。
- 密度目标 200–500 active/image（engineering bounds，非强制地图总量）。

## Explicit non-goals

- NO additional HKNN；NO additional plane fitting。
- 不改 ESKF；无 state feedback；无 FEJ；无 adaptive noise。
- 不创建 camera-only landmarks。

## Architectural invariants

- I-03：Visual 3D reference anchors 创建即冻结，不跟随 OctVox averaging。
- ADR-002 DECISION-13。

## Likely code seams

- `super_lio.cpp` Observe/UpdateMap 产物（effect_knn_idxs_、abcd_vec_、effect_mask_、points_body_v3_）。
- 新 `visual/VisualSelector`。

## Tests required

- projection unit（合成点云 + 合成相机）。
- component：selection 计数、grid 竞争（合成场景）。

## Acceptance criteria

- [ ] 全流程无重新执行 HKNN / plane fitting 的代码路径（static analysis + 调用计数器证明：HKNN/plane-fit 调用次数 == LIO 阶段次数）。
- [ ] 每帧 active 数落在 200–500（可观测；若无法达到，报告数据与原因，不得静默放宽）。
- [ ] 每个 image grid cell 最多保留 1 个候选。
- [ ] 创建的 landmark p_ref_world / normal_ref 冻结（后续 OctVox averaging 不影响其值，unit 断言）。
- [ ] active candidates/image 与 total VisualMap landmarks 分别计数并落盘。
- [ ] 复用路径对 LIO 帧内缓存生命周期依赖有明确处理（同帧有效；跨帧需显式保存，注释/文档说明）。

## Runtime / memory / debug artifacts

- visual_stats.csv：active/accepted/rejected 计数、每 grid cell 竞争统计。

## Failure rules

- FAIL：出现 re-HKNN、anchor 未冻结、grid 竞争失效、计数缺失。
- 允许改：质量打分、grid 参数、候选预筛阈值（均需记录为实验变量）。
- 禁止用于救场：降低创建门槛掩盖投影/标定错误；让 landmark 跟随 OctVox averaging。
